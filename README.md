# User-Service

Сервис управления пользователями, аутентификации и отслеживания присутствия (Presence).

## Основные возможности
- **Регистрация и Логин**: Создание аккаунтов и выдача JWT.
- **Профили**: Получение и обновление данных пользователя.
- **Статус Онлайн**: Отслеживание активности пользователей через WebSockets и Redis.
- **Администрирование**: Удаленный доступ к списку всех пользователей (для роли ADMIN).

---

## API Эндпоинты

### Аутентификация (Публичные)
- `POST /api/auth/register` — Регистрация.
- `POST /api/auth/login` — Логин.

### Профили (Защищенные Гейтвеем)
- `GET /api/users/:id` — Получить данные профиля.
- `PUT /api/users/update/:id` — Обновить свое имя или био.

### Администрирование
- `GET /api/admin/users` — Список всех юзеров (только для ADMIN).

### Сокеты
- `ws://.../api/presence/ws?token=...` — Подключение для фиксации статуса "В сети".

## Технологии
- **Go 1.25** + **Gin**
- **JWT (v5)**
- **Redis** (для хранения сессий и статусов)
- **PostgreSQL** (GORM)
